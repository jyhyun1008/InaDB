# 수익화 아이디어

> 전문 지식과 현재 활동을 연결한 수익 창출 방향

## 주역 × 천문 × 작곡 커미션

### 아이디어 개요

**"동양 천문학 전공자가 말아주는 별의 기운이 담긴 작곡 커미션"**

- 고천문학 전공 배경 + 주역 오라클 + 작곡 능력을 결합한 독자적인 커미션 서비스
- 의뢰자의 생년월일·현재 상황 등을 주역·동양 천문으로 해석하고, 그에 맞는 분위기의 BGM을 작곡해 납품

### 왜 이게 통할 수 있나?

- **차별화**: "BGM 커미션은 많지만 동양 점술 + 작곡" 조합은 매우 드묾
- **신뢰성 부여**: 학문적 배경(고천문학 전공)이 "야매 점술"과 선을 그어주는 근거
- **오라클 포지셔닝**: 주역 '오라클 카드'는 타로카드처럼 창의적 해석의 여지가 있어 엄밀한 정확도 부담 없음
- **Vtuber 연계**: 별/우주/신비 계열 세계관을 가진 Vtuber 아이덴티티와 자연스럽게 연결

### 커미션 구성안 (예시)

| 티어 | 내용 | 예상 가격대 |
|------|------|------------|
| 라이트 | 괘 1개 뽑아 분위기 지정 + 30~60초 BGM | 3~5만원 |
| 스탠다드 | 생년월일 기반 사주+괘 분석 + 1~2분 BGM (루프 포함) | 7~12만원 |
| 프리미엄 | 상담 포함 심층 해석 + 3~5분 풀 트랙 | 20만원+ |

### 준비 체크리스트

- [ ] 주역 오라클 카드 도착 후 기본 64괘 의미 학습 (한글 설명서 활용)
- [ ] 특히 음악과 연결할 수 있는 괘 키워드 정리 (예: 진震=우레→드라마틱, 손巽=바람→서정적 등)
- [ ] 샘플 BGM 제작 — 각 계절/절기 대응 분위기 별 데모 트랙 4~5개
- [ ] 커미션 소개 이미지(썸네일) + 설명글 준비
- [ ] 플랫폼 선택: 트위터/X, 픽시브, 스카이문살롱 등

### 리스크 및 주의점

- "점술"로 오해받을 경우 책임 문제 → 항상 **엔터테인먼트 / 창작 해석** 임을 명시
- 고천문학과 주역은 관련 있지만 직접적 전공이 아닐 수 있음 → "전공 배경을 바탕으로 공부한" 수준으로 솔직하게 표현
- 수요 테스트: 실제 커미션 오픈 전 설문이나 예약 이벤트로 수요 확인 권장

## 베이스 Vtuber × 음악 관련 수익화

### 슈퍼챗 / 팁 활성화

- 연주 방송, 악보 분석 방송 등 **음악 콘텐츠**에서 시청자 참여도가 높음
- "의뢰자의 희망 장르 즉흥 베이스 연주" 등 인터랙티브 요소

### BGM / 음원 판매

- DAW로 제작한 루프·BGM을 **Booth, GUMROAD** 등에 판매
- Vtuber나 스트리머용 배경음악은 꾸준한 수요 있음
- 주역 커미션 데모 트랙을 겸용 상품으로 활용 가능

### 악기 연주 강습

- 베이스 기타 입문자 대상 1:1 온라인 레슨
- Vtuber 정체성과 연결하면 "Vtuber에게 배우는 베이스" 콘셉트로 차별화
