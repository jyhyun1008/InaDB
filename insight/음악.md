# 음악 관련 인사이트

> 작곡(DAW), 베이스기타 활동에서 실제로 해볼 것들

---

## 화성학 지식 활용

### 코드 타입별 감성 연습

오늘 배운 3화음 종류를 DAW에서 직접 배치해보자. 각 코드 타입이 주는 분위기를 **귀로 체득**하는 게 중요하다.

- **메이저 → 마이너 전환**: 같은 루트에서 3음 하나만 반음 내리면 분위기가 완전히 달라짐. 이 차이를 의도적으로 쓰는 연습.
- **오그먼트 활용**: 메이저 코드에서 오그먼트로 갔다가 다시 돌아오는 진행. 몽환적이거나 불안한 느낌의 브리지 구간에 써볼 것.
- **디미니쉬 활용**: 크로매틱 하강 진행(A → Ab → G 등)에서 디미니쉬를 중간에 넣으면 재즈·클래식 분위기가 남.
- **Sus4 → 메이저 해결**: Csus4 → C 진행. 기타/베이스 인트로에서 자주 쓰이는 감성. DAW에서 피아노 롤에 배치해서 느낌 확인.

### 베이스라인 작성에 적용

- 코드 진행을 알면 베이스가 **근음만 치는 것 이상**의 라인을 만들 수 있음.
- 코드 타입에 따라 강조할 음이 달라짐:
  - 메이저: 근음 + 5음이 안전
  - 마이너: 근음 + 단3음 강조로 어두운 느낌 강화
  - 오그먼트: 반음 상행 크로매틱으로 연결 가능
  - 디미니쉬: 반음 하행으로 다음 코드로 연결하는 패싱 노트로 활용

### 조표 기반 키 설정 활용

- 작곡할 때 키를 정하면, 그 키의 다이어토닉 코드(7개)가 자동으로 정해짐.
- 조표 순서를 외워두면 임의의 키에서 다이어토닉 코드를 빠르게 파악 가능.
- 베이스 솔로 즉흥 연주 시, 해당 키의 스케일 음들이 뭔지 파악하는 기반이 됨.

## 보컬 연습 적용

### 프레이즈 일관성 훈련

보컬 레슨에서 배운 "수압 일정하게" 원리를 DAW와 연결해보자.

- **녹음 후 파형 확인**: DAW에서 보컬을 녹음하고 파형을 보면 음절별로 볼륨이 들쑥날쑥한지 한눈에 보인다. 파형이 일정하게 유지되는 걸 목표로 연습.
- **알파벳 전사 연습**: 한국어 가사를 로마자로 전사하여 음절보다 소리의 흐름에 집중하는 연습 시도
- [ ] 짧은 프레이즈(4마디 이내)를 반복 녹음하며 파형 비교 분석
- [ ] 한국어 노래 선택 후 알파벳 전사 버전 만들어보기

### 호흡 절약 훈련

- 긴 프레이즈를 **한 숨에** 끊지 않고 부르는 연습
- 목표: 8마디 이상의 긴 선율을 중간 숨 없이 소화
- [ ] 좋아하는 곡에서 긴 프레이즈를 골라 1주일 반복 연습

### 자음 처리

- 한국어 자음을 "짧게 건드리고 모음으로 넘어가는" 감각 훈련
- 특히 쌍자음처럼 들리는 구간(단어 경계 자음 연속) 의식적으로 체크
- [ ] 문제되는 구간 찾아 슬로우 템포로 분석 → 점진적 속도 증가

## 모듈레이션 이펙터 활용

### DAW에서 모듈레이션 실험

배운 이펙터 종류를 DAW의 플러그인으로 실제 체험해보기.

- **코러스**: 베이스 트랙에 코러스 걸어보기. Stereo Width 조절하며 입체감 차이 비교
- **트레몬로**: 드럼 없이 베이스+코드만 있는 루프에 트레몰로 걸어 리듬감 변화 실험
- **페이저**: 펑크(Funk) 장르 베이스 라인에 페이저 추가. Sly Stone, Bootsy Collins 느낌
- **플랜저·비브라토**: 솔로 라인이나 음 지속 구간에 소량 사용

- [ ] 각 이펙터를 걸었을 때와 안 걸었을 때 A/B 비교 녹음
- [ ] 코러스를 활용한 짧은 베이스 루프 제작

### 베이스 이펙터 페달 구성 참고

모듈레이션 계열 추가를 고민한다면 용도별 추천:
- 자주 쓸 것: **코러스** (MXR Bass Chorus Deluxe, Boss CE-2 계열)
- 펑크/그루브 쪽: **페이저** (EHX Small Stone, MXR Phase 90)

## 단음계 심화 이해 활용

### 이동도법으로 코드 기능 체감하기

이동도법을 실전에 적용하면 키를 바꿔도 "3음이 단3도인가 장3도인가"가 바로 느껴진다. DAW에서 작업할 때 키를 자유롭게 전환하며 코드를 짤 수 있게 된다.

- [ ] 같은 코드 진행을 C키, G키, D키로 각각 피아노 롤에 옮겨보기. 이동도법으로 "기능은 동일하다"를 체감하는 연습

### 단음계 파생 공식을 작곡에 활용

메이저 스케일에서 음을 내리는 것으로 세 단음계를 만드는 원리를 알면, **마이너 곡의 색감을 세밀하게 조절**할 수 있다.

- **자연단음계 기반**: 무난한 팝/록 마이너. 가장 보편적
- **화성단음계 7음(G#) 삽입**: 종지 직전 V 코드 앞에 G#을 넣어 극적인 해결감. 클래식·플라멩코 느낌
- **가락단음계 상행 선율**: 멜로디가 루트로 올라갈 때 6,7음을 올려 밝아지는 색감. 재즈·팝 발라드

- [ ] Am 기반 루프에서 E7 코드 앞에 G# 경유음을 베이스에 넣어보기
- [ ] 동일 멜로디를 자연단음계·가락단음계 버전으로 각각 만들어 색감 차이 비교

## 마이너 스케일 활용

### 세 가지 단음계를 DAW에서 직접 체험하기

오늘 배운 세 종류의 마이너 스케일을 피아노 롤에 직접 올려보고 **귀로 차이를 체득**하는 것이 중요하다.

- **자연단음계 → 화성단음계 변환**: Am 스케일에서 G를 G#으로 하나만 바꿔보기. 같은 루트에서 이국적 색감이 확 달라지는 걸 느낄 수 있다.
- **화성단음계의 V→i 해결감 체험**: E7 → Am 진행을 Em7 → Am과 비교해서 들어보기. 해결감의 강도 차이를 귀로 확인.
- **증2도의 활용**: 화성단음계의 F→G# 반음 간격을 멜로디 포인트로 쓰면 중동·플라멩코 느낌이 남. Vtuber 컨셉에 신비로운 색감 추가 가능.

### 마이너 스케일 기반 베이스라인 작성

- **자연단음계 기반**: 팝·록의 일반적인 마이너 베이스라인. 루트+5음+단3음 조합
- **화성단음계 기반**: Em7 대신 E7을 앞에 두는 진행. G#음을 베이스에 넣으면 강한 방향성 생김
- **완전5도 하행 + 화성단음계**: Am-Dm-G-C-F-Bdim-**E**-Am 진행에서 E 앞에 G#(화성단음계 7음)을 경유음으로 쓰는 베이스라인 시도

- [ ] A 자연/화성/가락단음계를 피아노 롤에 각각 올려서 비교 청취
- [ ] E7 → Am 해결 진행으로 4마디 루프 만들어보기
- [ ] 화성단음계 G# 음을 활용한 베이스 경유음 실험

## 펜타토닉 스케일 즉흥연주 활용

> 근거: [펜타토닉 스케일](../data/음악이론/펜타토닉-스케일.md)

### 베이스 애드립 입문으로 펜타토닉 쓰기

펜타토닉은 "어떤 코드 위에서도 크게 틀리지 않는" 음계다. 즉흥연주를 처음 시작하기에 가장 안전한 선택.

- **A 마이너 펜타토닉 박스 포지션 암기**: 모든 줄의 5번·7번 프렛만으로 구성. 한 포지션을 외우면 A 마이너 & C 메이저 펜타토닉 둘 다 커버
- **Am-Dm-G-C 진행 위에서 A 마이너 펜타토닉으로 즉흥 베이스라인 만들기**: 기존에 배운 다이어토닉 진행과 바로 연결 가능
- **블루스 스케일 도전**: 마이너 펜타토닉에 ♭5음 하나만 추가. 그루비한 펑크 느낌 나는 베이스라인에 활용

### DAW 작곡에서의 활용

- 멜로디 라인을 쓸 때 펜타토닉 안에서만 음을 고르면 어떤 코드에서도 잘 어울림 → 멜로디 작곡 속도 올라감
- 피아노 롤에서 스케일 퀀타이즈(Scale Quantize)를 펜타토닉으로 설정하면 건반을 아무데나 눌러도 펜타토닉 음만 나옴 (Logic: 스케일 퀀타이즈 설정, Ableton: 스케일 모드)

- [ ] A 마이너 펜타토닉 박스 포지션 외우고 4마디 즉흥 베이스라인 녹음
- [ ] DAW에서 스케일 퀀타이즈를 Minor Pentatonic으로 설정하고 멜로디 실험

## Logic Pro 패턴 리전 신기능 활용

> 근거: [Logic Pro 패턴 리전](../data/음악/Logic-Pro-패턴리전.md)

### 코드 트랙 연동으로 베이스 패턴 자동화

Logic Pro 12의 패턴 리전 + 코드 트랙 트래킹 조합은 코드 진행 기반 작업 속도를 크게 높인다.

**시도해볼 워크플로:**
1. 코드 트랙에 원하는 코드 진행 입력 (예: Am-F-C-G)
2. 소프트웨어 악기 트랙(베이스 또는 신스)에 패턴 리전 생성
3. 패턴 리전에서 코드 트랙 트래킹 ON
4. 패턴 안에 리듬만 짜면 → 음정은 코드 트랙이 자동으로 맞춰줌

이 방식이 익숙해지면 "코드 진행 하나로 베이스·아르페지오 패턴 동시에 테스트"하는 게 훨씬 빨라진다.

- [ ] Logic Pro 12 업데이트 확인 후 패턴 리전 코드 트랙 트래킹 기능 테스트
- [ ] 간단한 4코드 진행 + 패턴 리전으로 베이스 루프 만들어보기

## 스트링 편곡 실습

> 근거: [스트링 편곡법](../data/음악이론/스트링-편곡.md)

### DAW에서 스트링 편곡 시도하기

오늘 배운 Bottom → Top → Middle 순서를 실제로 DAW에서 적용해보자. 가장 빠른 방법은 이미 있는 코드 진행에 스트링을 얹는 것이다.

**추천 실습 순서:**

1. **첼로 트랙 먼저**: 코드 진행의 근음을 첼로에 배치. 예: C-Am-F-G 진행이면 각 코드마다 C, A, F, G 음
2. **더블베이스 트랙**: 첼로 MIDI를 복사하고 옥타브 다운(-12st). 이것만으로 저음이 두터워짐
3. **바이올린 1 탑노트**: 멜로디 또는 각 코드에서 가장 위에 올릴 코드톤 결정
4. **바이올린 2**: 바이올린 1 바로 아래 코드톤. 멜로디와 같은 방향으로 움직이도록 함
5. **비올라**: 남은 코드톤을 배치. 3음(3도) 중복 피하며 채우기

**무료 스트링 가상악기:**
- **Spitfire LABS (Strings)**: 무료 중 퀄리티 좋음, 다운로드 무료
- **BBCSO Discover**: Spitfire Audio의 무료 오케스트라 라이브러리

### 베이스+첼로 옥타브 유니즌

베이스기타를 치는 입장에서 흥미로운 포인트: 오케스트라에서 더블베이스+첼로가 옥타브 유니즌으로 저음을 만드는 것처럼, **베이스기타 + 옥타브 페달**로 비슷한 사운드 만들 수 있음.

### 스트링 편곡 연습 아이디어

- [ ] 4마디 코드 진행에 5성부 스트링 올리기 (Bottom → Top → Middle 순서 준수)
- [ ] Spitfire LABS 스트링 다운로드해서 DAW에 셋업
- [ ] 바이올린1 멜로디를 먼저 쓰고, 첼로부터 채워나가는 방식 vs 아래서부터 채우는 방식 비교

## 텐션 활용

> 근거: [텐션](../data/음악이론/텐션.md)

### 온음/반음 규칙으로 즉석에서 텐션 판단하기

새 코드를 보면 9·11·13을 각각 루트·3음·5음과 비교해서 온음이면 OK, 반음이면 스킵. 이 판단을 빠르게 하는 연습을 쌓으면 즉흥 연주에서 "안전한 음"을 실시간으로 고를 수 있다.

**외워두면 유용한 코드별 텐션 요약:**

| 코드 | 텐션 | 기억 포인트 |
|------|------|------------|
| Cmaj7 | T9, T13 | 11(F)은 항상 어보이드 |
| Fmaj7 | T9, T♯11, T13 | 세 개 다 됨 → 리디안의 특권 |
| G7 | T9, T13 (+얼터드) | 도미넌트는 얼터드까지 가능 |
| Dm7·Am7 | T9, T11 | 13은 피하기 |
| Em7 | **T11만** | 텐션 하나뿐인 까다로운 코드 |
| Bm7♭5 | T11, T♭13 | 9는 어보이드 |

### 7화음 → 텐션 추가로 색감 업그레이드

코드 진행에서 특정 코드에만 텐션을 넣어도 순간적인 색감 변화가 생긴다. 처음엔 하나씩 실험해보는 방식으로 접근하자.

**시도해볼 텐션 추가 순서:**

1. **G7(♯11)** — 리디안 도미넌트. G7에 F♯을 추가. 보사노바·재즈 퓨전에서 자주 나오는 색감
2. **G7(♭9)** — 얼터드 도미넌트 입문. D♭ 경과음 추가로 강한 해결감. Am(마이너 진행)으로 연결할 때 효과 극대화
3. **Fmaj7(♯11)** — 리디안 분위기의 정석. T9·T♯11·T13을 모두 쌓으면 Fmaj7이 가장 화려해진다

**베이스 텐션 경과음 실습:**
- G7 → C 진행에서 베이스: G → A♭(♭9) → G → C 처럼 A♭을 스쳐가는 크로매틱 장식음으로 활용
- Dm7(9,11) → G7(9,13) → Cmaj7(9,13) ii-V-I 전체에 텐션 입히기

- [ ] C장조 ii-V-I에 텐션을 입힌 버전(Dm7(9,11)→G7(♭9)→Cmaj7(9,13))을 DAW에 넣어보기
- [ ] G7 → Am 진행에서 G7(♭9) 사용해 마이너 해결감 강도 비교 청취

- [ ] 매일 랜덤 코드 이름 하나를 골라 포뮬라 → 구성음 도출 연습 (C·G·D·A·E·Bb 6키로 돌아가며)

### 다이어토닉 3화음 → 7화음 리하모나이즈

기존에 만든 코드 진행을 7화음으로 바꿔보는 연습. 가장 쉬운 색감 업그레이드다.

**단계별 적용:**
1. 기존 진행 예: Am - F - C - G
2. 7화음 버전: Am7 - Fmaj7 - Cmaj7 - G7
3. 더 나아가기: Am7 - Fmaj7 - Cmaj7 - G7sus4 → G7 (sus4 해결 추가)

- [ ] 현재 작업 중인 곡에서 코드를 전부 7화음으로 교체해보기
- [ ] 5도 하행 7화음 전체 진행(Cmaj7→Fmaj7→Bm7♭5→Em7→Am7→Dm7→G7→Cmaj7)을 DAW에 넣어보기

## 7화음 활용

> 근거: [7화음](../data/음악이론/7화음.md)

### 3화음 → 7화음으로 업그레이드하기

기존에 만든 코드 진행에서 3화음을 7화음으로 바꾸는 것만으로 곡의 색감이 한 단계 성숙해진다. 리하모나이제이션의 가장 쉬운 첫 걸음.

**시도해볼 진행 비교:**
- 기존: Am - F - C - G
- 7화음 버전: Am7 - Fmaj7 - Cmaj7 - G7

같은 코드 진행인데 팝 → 시티팝 느낌으로 색감이 바뀐다.

### 보사노바 스타일 진행 시도

Caug7이 보사노바에서 쓰인다는 것을 활용해서 보사노바 느낌의 짧은 루프를 만들어보자.

**크로매틱 하강 진행 (C 기준):**
```
Cmaj7 → Caug7 → C7 → C6
(G)     (G♯)    (G) → (A) 를 배경으로 베이스는 C 고정
```
이 진행은 최상성부가 G → G♯ → G → A로 반음 오르내리는 크로매틱한 움직임. 악기 하나에 입혀보면 보사노바 느낌이 확 난다.

- [ ] Cmaj7 → Caug7 → C7 → C6 루프를 DAW에서 만들어보기
- [ ] 기존 Am - F - C - G 진행을 7화음 버전으로 리하모나이즈

### ii-V-I 재즈 기본 진행

재즈에서 가장 핵심적인 진행. 7화음을 알면 바로 적용 가능하다.

**C장조 ii-V-I:**
```
Dm7 → G7 → Cmaj7
```

**A단조 ii-V-i (단조 버전):**
```
Bm7♭5 → E7 → Am
```

베이스로 이 진행의 루트만 잡아도 위에서 뭔 솔로를 쳐도 재즈처럼 들린다.

- [ ] C장조 ii-V-I 루프 4마디 만들기 (Dm7-G7-Cmaj7)
- [ ] Am 단조 ii-V-i로 어두운 분위기 루프 만들기 (Bm7♭5-E7-Am)

### 7화음 베이스라인에서의 활용

- **Cmaj7 진행**: B음(장7도)을 베이스 경과음으로 → C(루트) → B → G로 내려오는 선율 라인
- **G7 → C 해결**: G 베이스 + F음(단7도) 경과 → C로 해결하는 강한 방향성 활용
- **dim7 패싱**: Am - G♯dim7 - G 처럼 반음씩 크로매틱하게 연결하는 베이스라인

## 하이브리드 코드 활용

> 근거: [하이브리드 코드](../data/음악이론/하이브리드-코드.md)

### 하이브리드 코드로 진행에 색감 넣기

일반적인 G7 대신 하이브리드 코드를 도미넌트 자리에 쓰면 해결감이 더 부드럽고 풍성해진다. 4가지 형태를 DAW 피아노 롤에 차례로 올려보고 귀로 차이를 확인해보자.

**G → C 진행에서의 대체 실험:**

| 원래 코드 | 하이브리드 버전 | 색감 차이 |
|---------|------------|---------|
| G7 | F/G | 더 부드럽고 팝적 |
| G7 | Fmaj7/G | 시티팝·재즈 느낌 |
| G7 | Dm7/G | 넓고 개방적인 느낌 |

**베이스에서의 활용:**

- F/G를 연주할 때 베이스는 G 루트를 잡고, 위 악기들이 F 코드 보이싱(F·A·C)을 담당하면 된다.
- 베이스 솔로에서 G 위에 A(T9)나 C(sus4)를 경과음으로 쓰면 하이브리드 느낌의 라인이 만들어진다.
- Dm/G처럼 sus4 없이도 하이브리드로 분류되므로, D음을 베이스 경과음으로 사용해도 충분히 그 분위기가 난다.

### Vtuber BGM 작곡에서 활용

도미넌트→토닉 해결 직전에 하이브리드 코드를 한 박 끼워 넣으면 **몽환적이고 세련된 색감**이 생긴다. 특히 Fmaj7/G → Cmaj7 진행은 일반적인 G7→C보다 훨씬 시티팝적이다.

- [ ] Am - F/G - C 진행과 Am - G7 - C 진행을 비교 청취
- [ ] Fmaj7/G → Cmaj7 진행을 4마디 루프로 만들어보기
- [ ] 기존 곡 진행의 도미넌트 코드를 하이브리드 버전으로 교체해보기
- [ ] 하이브리드 코드 넣어서 새 곡 만들어보기
