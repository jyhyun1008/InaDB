
# Logic Pro 패턴 리전 (Pattern Region)

## 패턴 리전이란?

**패턴 리전(Pattern Region)**은 Logic Pro에서 제공하는 스텝 시퀀서 기반의 리전 타입이다. 일반 MIDI 리전처럼 음표를 피아노 롤에 그리는 것이 아니라, **그리드(격자) 방식으로 스텝을 켜고 끄는 방식**으로 패턴을 만든다.

드럼 머신이나 TR-808 같은 하드웨어 시퀀서의 사용 방식을 소프트웨어로 구현한 것이라고 보면 된다.

---

## Logic Pro 12의 패턴 리전 신기능

기존 패턴 리전은 고정된 음정으로만 동작했는데, Logic Pro 12부터 **키 트래킹**과 **코드 트랙 트래킹** 기능이 추가됐다.

### 키 트래킹 (Key Tracking)

패턴 안의 음들이 **프로젝트에 설정된 키(조성)**에 맞춰 자동으로 조정된다.

예: 프로젝트 키가 C 메이저에서 G 메이저로 바뀌면, 패턴 안의 음들이 G 메이저 스케일 음들로 자동 이동.

### 코드 트랙 트래킹 (Chord Track Tracking)

**Logic의 코드 트랙(Chord Track)**과 패턴 리전을 연동시키면, 코드가 바뀔 때마다 패턴 안의 음들이 **해당 코드의 코드톤**으로 자동 이동한다.

예: 코드 트랙에서 C → Am → F → G 진행이 있고, 패턴 리전에 루트음 패턴이 있으면:
- C 구간 → C음
- Am 구간 → A음
- F 구간 → F음
- G 구간 → G음
이걸 **일일이 피아노 롤에서 수정하지 않아도 자동으로 바뀐다.**

---

## 왜 유용한가?

기존에는 코드 진행이 바뀔 때마다 베이스라인이나 아르페지오 패턴의 MIDI 음정을 **구간마다 손으로 수정**해야 했다. 이제는 패턴 하나만 만들어두면, 코드 트랙이 알아서 음정을 맞춰준다.

**실제 활용 시나리오:**
1. 코드 트랙에 코드 진행 입력
2. 베이스 트랙에 패턴 리전으로 리듬 패턴 제작 (어떤 스텝을 치는지)
3. 코드 트랙 트래킹 ON
4. 코드가 바뀔 때마다 베이스의 루트음이 자동으로 따라감

---

## 코드 트랙 (Chord Track)이란?

Logic Pro의 기능으로, 타임라인에 코드를 시각적으로 표시하는 전용 트랙이다. 여기에 입력된 코드 정보를 다른 트랙이나 기능들이 참조할 수 있다.

- 스케일 퀀타이즈(Scale Quantize)와 연동 가능
- 패턴 리전 트래킹과 연동 가능
- 악보 보기에서 코드 표시로도 활용
