# 캐릭터 디자인: 마인드맵과 삼면도

## 마인드맵으로 캐릭터 설정하기

### 왜 마인드맵인가?

캐릭터를 처음부터 그리기 시작하면 "귀엽게 생긴 캐릭터"는 만들어지지만, **이 캐릭터가 누구인지**가 불명확해지기 쉽다. 마인드맵은 먼저 정체성을 잡고, 거기서 시각적 요소를 도출하는 방식이다.

### 과정

1. 중심에 "내가 좋아하는 것"을 쓴다.
2. 거기서 연상되는 키워드를 뻗어나간다.
3. 반복해서 구체적인 시각 언어(색, 형태, 소재, 분위기)로 이어지게 한다.

**예시: "바다를 좋아함"**
```
바다
├── 파란색, 청록색
├── 물결 → 곡선 실루엣
├── 해파리 → 반투명, 발광
├── 깊은 곳 → 미지의 느낌, 신비로운 눈빛
├── 조용함 → 차분한 성격
└── 모래사장 → 베이지, 따뜻한 포인트 색
```

이 키워드들이 캐릭터의 **색상 팔레트, 의상 소재, 성격, 소품**으로 연결된다.

### Vtuber 캐릭터에 적용할 때

Vtuber 캐릭터는 단순히 귀엽고 예쁜 것 이상으로, **본인의 정체성**이 녹아들어야 시청자가 더 친근하게 느낀다. 마인드맵으로 추출된 키워드가 많을수록 캐릭터에 설득력이 생긴다.

## 삼면도 (三面圖 / Turn-around Sheet)

### 삼면도란?

캐릭터를 **정면·측면·후면**(또는 정면·반측면·측면) 등 여러 각도에서 그린 레퍼런스 자료다. 애니메이션·게임·Vtuber 모델 제작 시 필수적이다.

### 삼면도가 필요한 이유

정면만 그린 캐릭터는 옆에서 보면 비율이 이상해지거나, 후면이 어떻게 생겼는지 알 수 없다. 삼면도가 있으면:
- 작화 일관성 유지 (아니메이터가 여러 명이어도 같은 캐릭터처럼 보임)
- 3D 모델러나 Live2D 제작자에게 명확한 가이드 제공
- 본인도 캐릭터를 그릴 때 흔들리지 않음

### 캐릭터 시트 구성 요소

완성도 높은 캐릭터 레퍼런스 시트에는 다음이 들어간다:

| 요소 | 설명 |
|------|------|
| **삼면도** | 정면/측면/후면, 가능하면 반측면도 |
| **의상 디테일** | 단추, 문양, 지퍼, 소재 질감 등 확대 |
| **표정 모음** | 기쁨·화남·슬픔·무표정·당황·웃음 등 |
| **신장 가이드** | 머리 몇 개 크기인지(두신) 표시 |
| **색상 팔레트** | 사용된 색의 정확한 색코드 |
| **초안 스케치** | 초기 아이디어나 채택 안 된 디자인들 |
| **소품** | 무기, 가방, 악기 등 함께 나오는 소품 |

## Vtuber 모델 제작 의뢰 시 활용

모델 제작을 외주 줄 때 캐릭터 시트가 완성도 있을수록 의뢰자-작업자 간 미스커뮤니케이션이 줄어든다. 최소한 다음은 준비하는 게 좋다:
- 정면도 (컬러 완성본)
- 표정 모음 (Live2D의 경우 특히 중요)
- 의상 색상 팔레트

---

## 일러스트 작업 흐름

1. **마인드맵** → 콘셉트 키워드 추출
2. **러프 스케치** 여러 개 → 방향성 결정
3. **정면 완성도 높이기**
4. **삼면도 완성**
5. **표정집 작성**
6. **색상 팔레트 정리**

## 레퍼런스 수집: 핀터레스트 활용

### 왜 레퍼런스를 모아야 하나?

아무것도 없이 그리기 시작하면 "내가 그릴 수 있는 것"의 범위를 못 벗어난다. 레퍼런스는:
- 원하는 **스타일·분위기**를 시각적으로 정의해줌
- 의뢰자(클라이언트)와 소통 시 말로 설명하기 어려운 것을 이미지로 대체
- 본인이 좋아하는 것의 패턴을 발견하게 해줌

### 핀터레스트(Pinterest) 활용법

- **보드(Board)**: 주제별로 이미지를 모으는 기능. 용도에 따라 분류 가능
  - 예: "캐릭터 의상 레퍼런스", "색감 팔레트", "포즈 참고", "Vtuber 디자인"
- **시크릿 보드**: 공개하기 싫은 레퍼런스는 비공개로 저장
- **검색 팁**: 영어로 검색하면 훨씬 방대한 결과
  - 예: `fantasy bass player character`, `vtuber design reference`, `JP indie vtuber art style`

### 레퍼런스 종류별 수집 전략

| 종류 | 수집 목적 |
|------|-----------|
| 스타일 레퍼런스 | 선의 느낌, 채색 방식, 전반적 화풍 |
| 포즈 레퍼런스 | 자연스러운 몸의 각도 |
| 색감 레퍼런스 | 색 조합, 팔레트 |
| 의상 레퍼런스 | 옷 주름, 소재 표현, 디테일 |
| 세계관 레퍼런스 | 배경, 소품, 분위기 |
