# 코드 넘버링 (코드 포뮬라)

## 코드 포뮬라란?

**코드 포뮬라(Chord Formula)**는 코드를 이루는 각 음을 **숫자와 기호**로 표현하는 방법이다. 루트(1)를 기준으로 다른 음들이 얼마나 위에 있는지를 숫자로 나타낸다.

예를 들어 메이저 트라이어드는 `1, 3, 5`다. 이 공식에서 C를 루트(1)로 정하면 C(1)-E(3)-G(5)가 되고, G를 루트로 정하면 G(1)-B(3)-D(5)가 된다. **키가 바뀌어도 공식은 동일**하다.

---

## 표기 규칙

| 음정 종류 | 표기 | 설명 |
|-----------|------|------|
| 장(Major) 음정 | 숫자만 | 메이저 스케일 기준 자연스러운 음정 |
| 완전(Perfect) 음정 | 숫자만 | 1도(루트), 4도, 5도, 8도 |
| 단(Minor) 음정 | **b + 숫자** | 장음정에서 반음 내린 것 |
| 증(Augmented) 음정 | **# + 숫자** | 완전/장음정에서 반음 올린 것 |
| 감(Diminished) 음정 | **b + 단음정 숫자** | 단음정에서 반음 더 내린 것 |

> 기준이 되는 숫자(1, 2, 3, 4, 5, 6, 7)는 항상 **메이저 스케일의 해당 음정**을 가리킨다.

| sus2 | 1, 2, 5 | C D G | 2 + 5 |

## 주요 7화음 포뮬라

| 코드 종류 | 포뮬라 | C 기준 | 특징 |
|-----------|--------|--------|------|
| 메이저 세븐 (maj7) | 1, 3, 5, 7 | C E G B | 장7도 — 따뜻하고 몽환적 |
| 도미넌트 세븐 (7) | 1, 3, 5, b7 | C E G Bb | 단7도 — 강한 해결 욕구 |
| 마이너 세븐 (m7) | 1, b3, 5, b7 | C Eb G Bb | 어둡고 부드러운 긴장 |
| 마이너 메이저 세븐 (mMaj7) | 1, b3, 5, 7 | C Eb G B | 어두우면서 날카로운 긴장 |
| 하프 디미니쉬 (m7b5 / ø7) | 1, b3, b5, b7 | C Eb Gb Bb | 재즈 단조 ii 코드 |
| 디미니쉬 세븐 (dim7 / °7) | 1, b3, b5, bb7 | C Eb Gb A | 극도의 불안, 완전 대칭 |
| 오그먼트 세븐 (aug7 / 7#5) | 1, 3, #5, b7 | C E G# Bb | 몽환적 긴장, 보사노바 |
| 세븐 sus4 (7sus4) | 1, 4, 5, b7 | C F G Bb | 해결을 미루는 부유감 |

## 확장 코드 포뮬라 맛보기

코드 포뮬라는 9화음, 11화음, 13화음 같은 **확장 화음(Extended Chord)**에도 그대로 적용된다. 7을 넘으면 한 옥타브 위의 음을 더 얹는다.

| 코드 | 포뮬라 | 의미 |
|------|--------|------|
| C9 | 1, 3, 5, b7, 9 | C7에 2도(한 옥타브 위) 추가 |
| Cmaj9 | 1, 3, 5, 7, 9 | Cmaj7에 2도 추가 |
| C13 | 1, 3, 5, b7, 9, 11, 13 | C7에 6도까지 전부 추가 |
| C7#9 | 1, 3, 5, b7, #9 | "지미 헨드릭스 코드"로 유명한 코드 |

## 포뮬라로 코드 직접 만들기

**실습 예시: G aug7을 만들어보자**

포뮬라: `1, 3, #5, b7`

1. 루트(1) = G
2. 3도 = B (G에서 장3도 위)
3. #5도 = D♯ (G에서 증5도 위, 즉 완전5도 D를 반음 올림)
4. b7도 = F (G에서 단7도 위)

→ **G aug7 = G B D♯ F**

이 방식으로 어떤 코드든 루트만 바꾸면 새로운 키의 같은 코드를 즉석에서 만들 수 있다.

---

## 왜 중요한가?

- 새로운 코드 이름을 봤을 때 **포뮬라로 분해**하면 구성음을 바로 파악 가능
- 전위(Inversion), 변형 코드도 포뮬라로 추적 가능
- 즉흥 연주나 편곡에서 코드 톤을 **근거 있게** 선택하게 됨
- DAW에서 피아노 롤에 코드를 넣을 때 포뮬라를 기억하면 어떤 키에서든 빠르게 입력 가능
