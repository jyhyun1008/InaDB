# 모드 (Mode / 선법)

## 모드란?

**모드(Mode)**는 메이저 스케일의 7개 음을 **어느 음에서 시작하느냐**에 따라 만들어지는 7가지 음계다. 서양 음악이 조성 체계로 정착하기 전, 중세 교회 음악에서 사용된 오래된 선법(旋法)에서 유래했다.

C Major의 음(C D E F G A B)을 그대로 두고 시작음만 바꾸면 7가지 다른 음계가 나온다. 각각 고유한 색깔과 분위기가 있어 장르별로 활발하게 쓰인다.

---

## 7가지 모드 총정리

각 모드를 이해하는 방법은 두 가지다.

- **상대적 방법**: "어떤 메이저 스케일의 몇 번째 음에서 시작하는가"
- **병렬 방법**: "메이저 스케일에서 무엇이 달라지는가 (포뮬라)"

### 1. 아이오니안 (Ionian) — 메이저 스케일 그 자체

| 항목 | 내용 |
|------|------|
| 포뮬라 | 1 2 3 4 5 6 7 |
| C 기준 음 | C D E F G A B |
| 상대 키 | C Ionian = **C Major** |
| 느낌 | 밝고 안정적, 행복함 |
| 장르 | 팝, 동요, 클래식 |

### 2. 도리안 (Dorian) — 마이너인데 왜 이렇게 쿨하지?

| 항목 | 내용 |
|------|------|
| 포뮬라 | 1 2 **b3** 4 5 6 **b7** |
| C 기준 음 | C D Eb F G A Bb |
| 상대 키 | C Dorian = **Bb Major**의 2번째 음에서 시작 |
| 느낌 | 마이너이지만 6음이 장음정 → 어둡지만 세련되고 쿨한 느낌 |
| 장르 | 재즈, 펑크(Funk), R&B, 소울, 록 솔로 |
| 유명 예시 | Miles Davis "So What", Daft Punk의 많은 곡, "Sultans of Swing" |

> 베이스 관점에서 **가장 자주 쓰이는 마이너 모드**. 마이너 7화음(Dm7, Am7 등) 위에서 도리안으로 접근하면 재즈·펑크 느낌이 살아난다.

### 3. 프리지안 (Phrygian) — 어둡고 이국적인

| 항목 | 내용 |
|------|------|
| 포뮬라 | 1 **b2** **b3** 4 5 **b6** **b7** |
| C 기준 음 | C Db Eb F G Ab Bb |
| 상대 키 | C Phrygian = **Ab Major**의 3번째 음에서 시작 |
| 느낌 | 매우 어둡고 위협적, 스페인·플라멩코·중동 분위기 |
| 장르 | 플라멩코, 헤비메탈, 아니메 BGM, 보스 배틀 BGM |
| 유명 예시 | Metallica "Wherever I May Roam", 많은 게임 보스전 BGM |

> 특히 **b2도(반음 위 음)**가 핵심 특징. 루트 바로 위 반음 음이 강하게 등장할 때 프리지안 특유의 긴장감이 나온다. Vtuber 컨셉에서 강렬하거나 신비로운 캐릭터 BGM에 활용 가능.

### 4. 리디안 (Lydian) — 꿈결 같은 빛

| 항목 | 내용 |
|------|------|
| 포뮬라 | 1 2 3 **#4** 5 6 7 |
| C 기준 음 | C D E F# G A B |
| 상대 키 | C Lydian = **G Major**의 4번째 음에서 시작 |
| 느낌 | 메이저인데 #4 때문에 공중에 떠있는 듯한 몽환적·신비로운 느낌 |
| 장르 | 영화 OST, 앰비언트, 시티팝, 드림팝 |
| 유명 예시 | John Williams의 "E.T.", "쥬라기 공원"; 드래곤볼 "Cha-La Head-Cha-La" 일부 |

> **#4음이 포인트**. F# 하나가 C 메이저와 C 리디안을 가른다. 아르페지오에서 이 음을 지나갈 때 반짝이는 느낌이 특히 강하게 난다.

### 5. 믹소리디안 (Mixolydian) — 블루스·록의 엔진

| 항목 | 내용 |
|------|------|
| 포뮬라 | 1 2 3 4 5 6 **b7** |
| C 기준 음 | C D E F G A Bb |
| 상대 키 | C Mixolydian = **F Major**의 5번째 음에서 시작 |
| 느낌 | 메이저인데 b7 때문에 긴장감이 남아 "해결이 안 된 메이저" 느낌 |
| 장르 | 블루스, 록, 컨트리, 하드록 |
| 유명 예시 | Beatles "Norwegian Wood", "Sweet Home Chicago", AC/DC 리프 대부분 |

> **도미넌트 7화음(G7 등)과 같은 구성**. G 믹소리디안 = G7 코드 위에서 쓸 수 있는 스케일. 블루스 베이스라인에서 7음(F)을 경과음으로 활용하면 바로 록/블루스 느낌이 난다.

### 6. 에올리안 (Aeolian) — 자연단음계

| 항목 | 내용 |
|------|------|
| 포뮬라 | 1 2 **b3** 4 5 **b6** **b7** |
| C 기준 음 | C D Eb F G Ab Bb |
| 상대 키 | C Aeolian = **Eb Major**의 6번째 음에서 시작 |
| 느낌 | 어둡고 슬프거나 차분한, 가장 보편적인 마이너 |
| 장르 | 팝·록의 모든 마이너 장르 |

> 자연단음계와 동일하다. 도리안과 비교했을 때 6음이 Ab(단6도)라는 점이 다름. 도리안이 "쿨한 마이너"라면 에올리안은 "무난한 마이너".

### 7. 로크리안 (Locrian) — 이론상 존재

| 항목 | 내용 |
|------|------|
| 포뮬라 | 1 **b2** **b3** 4 **b5** **b6** **b7** |
| C 기준 음 | C Db Eb F Gb Ab Bb |
| 상대 키 | C Locrian = **Db Major**의 7번째 음에서 시작 |
| 느낌 | 극도의 불안정. 완전5도조차 감5도(트라이톤)라 토닉으로서 안정감이 없음 |
| 장르 | 이론적으로만 주로 사용, 재즈에서 VIIm7♭5 위에 간혹 사용 |

> 실제로 곡 전체를 로크리안으로 쓰는 경우는 거의 없다. 다이어토닉 7화음의 VIIm7♭5 코드 위에서 짧게 활용되는 정도.

## 모드 한눈에 비교 (C 기준)

| 모드 | 음 구성 | 다른 점 | 느낌 요약 |
|------|---------|---------|-----------|
| Ionian | C D E F G A B | (기준) | 밝고 안정 |
| Dorian | C D **Eb** F G A **Bb** | b3, b7 | 쿨한 마이너 |
| Phrygian | C **Db Eb** F G **Ab Bb** | b2, b3, b6, b7 | 어둡고 이국적 |
| Lydian | C D E **F#** G A B | #4 | 몽환·부유 |
| Mixolydian | C D E F G A **Bb** | b7 | 블루스·록 |
| Aeolian | C D **Eb** F G **Ab Bb** | b3, b6, b7 | 무난한 마이너 |
| Locrian | C **Db Eb** F **Gb Ab Bb** | b2, b3, b5, b6, b7 | 극도의 불안 |

## 상대 키 관계 정리 (C 모드 기준)

| C 모드 | 상대 메이저 키 | C는 몇 번째 음 |
|--------|--------------|----------------|
| C Ionian | C Major | 1번째 |
| C Dorian | Bb Major | 2번째 |
| C Phrygian | Ab Major | 3번째 |
| C Lydian | G Major | 4번째 |
| C Mixolydian | F Major | 5번째 |
| C Aeolian | Eb Major | 6번째 |
| C Locrian | Db Major | 7번째 |

외우는 방법: 5도권을 거꾸로 거슬러 올라가면서 각 모드가 배치된다.
(C → Bb → Ab → Gb… 방향)

## 베이스에서의 활용

| 상황 | 추천 모드 |
|------|-----------|
| 마이너 7화음(Dm7, Am7 등) 위 재즈·펑크 솔로 | **도리안** |
| 도미넌트 7화음(G7, C7 등) 위 블루스·록 | **믹소리디안** |
| 어두운 리프·보스전 BGM 느낌 | **프리지안** |
| 몽환적 패시지, 영화 OST 느낌 | **리디안** |
| 일반적인 마이너 진행 | **에올리안** |
