# 화성학: 3화음과 조표

## 3화음이란?

**3화음(Triad)**은 3개의 음을 3도 간격으로 쌓아 만든 화음이다. 코드(chord)의 가장 기본 단위.

- 가장 아래 음: **근음(Root)**
- 가운데 음: **3음(Third)**
- 맨 위 음: **5음(Fifth)**

예: C 메이저 = C(도) + E(미) + G(솔)

---

## 음정 기초

3화음의 종류를 이해하려면 **장3도**와 **단3도**의 개념이 필요하다.

- **장3도 (Major 3rd)**: 반음 4개 간격 (예: C→E)
- **단3도 (Minor 3rd)**: 반음 3개 간격 (예: C→Eb)

피아노 건반 기준으로, 흰 건반+검은 건반 모두 포함해서 세면 된다.

---

## 3화음의 종류

### 메이저 3화음 (Major Triad)

- **구성**: 장3도 + 단3도
- **느낌**: 밝고 안정적, 긍정적
- **표기**: C, D, E, F, G, A, B (알파벳 단독)
- **예**: C 메이저 = C + E + G

가장 기본적이고 많이 쓰이는 화음. 팝, 록, 동요 등 장르 불문 등장한다.

### 마이너 3화음 (Minor Triad)

- **구성**: 단3도 + 장3도
- **느낌**: 어둡고 슬프거나 차분한
- **표기**: Cm, Dm, Em... (소문자 m 또는 min)
- **예**: C 마이너 = C + Eb + G

감성적인 곡, 슬픈 발라드, 어두운 장르에 자주 쓰인다.

### 오그먼트 3화음 (Augmented Triad)

- **구성**: 장3도 + 장3도
- **느낌**: 불안정하고 긴장감, 몽환적
- **표기**: Caug, C+ (aug 또는 + 기호)
- **예**: C 오그먼트 = C + E + G#

5음이 반음 올라간 형태. 영화 OST나 재즈에서 독특한 색감을 줄 때 사용된다.

### 디미니쉬 3화음 (Diminished Triad)

- **구성**: 단3도 + 단3도
- **느낌**: 매우 불안정, 긴장·공포
- **표기**: Cdim, C° (dim 또는 ° 기호)
- **예**: C 디미니쉬 = C + Eb + Gb

공포 영화 BGM, 서스펜스 장면에서 자주 들린다. 해결이 필요한 긴장감을 만들어낸다.

### 서스펜드 화음 (Suspended Chord)

- **구성**: 3음 대신 2도 또는 4도 사용
  - **Sus4**: 근음 + 완전4도 + 완전5도 (예: C + F + G)
  - **Sus2**: 근음 + 장2도 + 완전5도 (예: C + D + G)
- **느낌**: 열린 느낌, 여운, 해결을 기다리는 느낌
- **표기**: Csus4, Csus2

Sus4는 메이저나 마이너로 해결하기 직전의 긴장감을 표현할 때 자주 쓰인다. 팝 인트로나 기타 아르페지오에서 많이 들린다.

## 조표 붙는 순서

**조표(Key Signature)**는 악보의 박자표 왼쪽에 붙어서 "이 곡은 어떤 키(조)입니다"를 알려주는 기호다.

### 샵(♯) 붙는 순서 — **파·도·솔·레·라·미·시**

```
F → C → G → D → A → E → B
```

외우는 방법: "파도솔레라미시"

| 샵 개수 | 장조 | 단조 |
|---------|------|------|
| 1개 (F♯) | G장조 | E단조 |
| 2개 (+C♯) | D장조 | B단조 |
| 3개 (+G♯) | A장조 | F♯단조 |
| 4개 (+D♯) | E장조 | C♯단조 |
| 5개 (+A♯) | B장조 | G♯단조 |
| 6개 (+E♯) | F♯장조 | D♯단조 |
| 7개 (+B♯) | C♯장조 | A♯단조 |

### 플랫(♭) 붙는 순서 — **시·미·라·레·솔·도·파**

```
B → E → A → D → G → C → F
```

외우는 방법: "시미라레솔도파"

| 플랫 개수 | 장조 | 단조 |
|-----------|------|------|
| 1개 (B♭) | F장조 | D단조 |
| 2개 (+E♭) | B♭장조 | G단조 |
| 3개 (+A♭) | E♭장조 | C단조 |
| 4개 (+D♭) | A♭장조 | F단조 |
| 5개 (+G♭) | D♭장조 | B♭단조 |
| 6개 (+C♭) | G♭장조 | E♭단조 |
| 7개 (+F♭) | C♭장조 | A♭단조 |

샵과 플랫의 순서는 서로 정반대임을 알 수 있다.

### 빠르게 키 파악하는 법

- **샵**: 마지막 샵의 반음 위가 그 장조의 키. (마지막 샵이 F♯이면 G장조)
- **플랫**: 마지막에서 두 번째 플랫이 그 장조의 키. (B♭, E♭이면 B♭장조)

## 베이스에서의 활용

베이스기타 연주 관점에서:
- 코드 타입을 알면 어떤 음을 강조할지 파악 가능 (근음, 5음, 3음 순으로 중요도가 다름)
- 디미니쉬·오그먼트의 반음 진행을 활용한 크로매틱 워킹 베이스라인
- Sus 코드는 베이스가 근음을 잡고 위에서 해결되는 느낌을 주기 좋음
- 조표를 알면 즉흥 연주(잼) 시 어떤 음이 안전한지 파악하기 쉬움
