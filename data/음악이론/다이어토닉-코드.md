# 다이어토닉 코드 (Diatonic Chords)

## 다이어토닉이란?

**다이어토닉(Diatonic)**은 "조성 안에 속하는"이라는 의미다. 특정 키(key)의 음계 안에서만 음을 사용해 만든 코드가 다이어토닉 코드다. 임시표(#, b)를 추가하지 않으므로, 곡의 분위기를 해치지 않고 가장 안전하게 쓸 수 있는 코드들이다.

C장조라면 C·D·E·F·G·A·B 7개 음만 사용 → 이 7음 위에 3화음을 쌓으면 7개의 다이어토닉 코드가 나온다.

---

## 메이저 키의 다이어토닉 3화음

### 구조 (C장조 예시)

| 도수 | 코드 | 종류 | 기능 |
|------|------|------|------|
| I    | C    | 메이저 | 토닉 |
| ii   | Dm   | 마이너 | 서브도미넌트 |
| iii  | Em   | 마이너 | 토닉 |
| IV   | F    | 메이저 | 서브도미넌트 |
| V    | G    | 메이저 | 도미넌트 |
| vi   | Am   | 마이너 | 토닉 |
| vii° | Bdim | 디미니쉬 | (논쟁 있음) |

**외우는 법**: 메마마메메마디 (메이저·마이너·마이너·메이저·메이저·마이너·디미니쉬)

### 코드 기능 (Function)

| 기능 | 역할 | 해당 코드 |
|------|------|-----------|
| **토닉(T)** | 집, 안정, 시작과 끝 | I, iii, vi |
| **서브도미넌트(S)** | 집을 떠남, 이동 | IV, ii |
| **도미넌트(D)** | 귀환 직전 긴장감 | V |

기본 진행: **T → S → D → T** (집 → 출발 → 긴장 → 귀환)

## 주요 3화음과 부 3화음

### 주요 3화음

**I, IV, V** — 가장 핵심이 되는 코드 3개. 이 3개만으로도 대부분의 곡을 커버할 수 있다.

### 부 3화음 (대리 코드)

**ii, iii, vi, vii°** — 주요 3화음을 **대리(Substitute)**할 수 있다.

| 대리 관계 | 공통음 | 이유 |
|-----------|--------|------|
| vi → I 대리 | C·E (Am과 C 공유) | 토닉 기능 유사 |
| ii → IV 대리 | F·A (Dm과 F 공유) | 서브도미넌트 기능 유사 |
| iii → I 또는 V 대리 | 두 코드와 음 공유 | 애매하게 두 기능 사이 |

이 대리 관계를 이용하면 **I-IV-V-I** 외에 훨씬 다양한 코드 진행이 가능하다. 예:
- I-IV-V-I → I-ii-V-I (ii가 IV 대리)
- vi-IV-I-V (팝에서 흔한 vi 시작 진행)

## vii°(디미니쉬)의 기능 논쟁

**Bdim(시·레·파)**은 도미넌트인가 아닌가?

### 도미넌트로 보는 입장
- G7 코드(솔·시·레·파)에서 **G(근음)만 뺀 형태**
- 핵심 긴장 음정인 **트라이톤(시↔파)** 포함
- C로 강하게 해결하려는 충동 → 도미넌트 기능

### 독립적으로 보는 입장
- 도미넌트의 핵심인 **G음(5도음) 없음**
- 디미니쉬 특유의 불안정한 음색이 독자적
- 토닉·서브도미넌트·도미넌트 중 어느 것도 아닌 특수 코드

→ 어떤 이론서를 쓰느냐에 따라 다르다. 둘 다 틀린 게 아님.

## 마이너 키의 다이어토닉 코드

A 자연단조(Am scale) 예시:

| 도수 | 코드 | 종류 |
|------|------|------|
| i    | Am   | 마이너 |
| ii°  | Bdim | 디미니쉬 |
| III  | C    | 메이저 |
| iv   | Dm   | 마이너 |
| v    | Em   | 마이너 |
| VI   | F    | 메이저 |
| VII  | G    | 메이저 |

마이너 키에서는 **v(Em)**가 마이너라서 도미넌트 느낌이 약하다. 이 때문에 7번 음을 반음 올린 **화성 단조(Harmonic Minor)**를 사용해 **V(E 메이저)** 코드를 만들기도 한다. → 훨씬 강한 해결감.

---

## 베이스 연주에서의 활용

- 코드 타입을 알면 **근음 이외의 음**을 경과음으로 사용 가능
- 다이어토닉 코드 진행을 알면 **다음 코드를 예측**하고 준비할 수 있음
- ii-V-I 같은 재즈 기본 진행도 다이어토닉 코드 관계에서 출발
