# 7화음 (Seventh Chords)

## 7화음이란?

**7화음**은 3화음(트라이어드) 위에 **7도 음정**을 하나 더 쌓은 4음 화음이다. 루트 기준으로 위에서 세어 보면 근음·3음·5음·7음이 된다.

3화음이 빵이라면, 7화음은 거기에 버터를 한 겹 더 바른 것. 색감이 한층 더 풍부해지면서 팝·재즈·보사노바·R&B 등 현대 음악의 거의 모든 장르에 걸쳐 쓰인다.

---

## 기본 개념: 7도 음정

7도는 근음에서 7번째 음까지의 간격이다.

| 음정 이름 | 반음 수 | C 기준 |
|-----------|---------|--------|
| 장7도 (Major 7th) | 11 | B |
| 단7도 (Minor 7th) | 10 | B♭ |
| 장6도 (Major 6th) | 9 | A |
| 감7도 (Diminished 7th) | 9 | A (= B♭♭) |

> 장6도와 감7도는 같은 음이지만(이명동음), 코드 이론에서는 어떤 화음인지에 따라 다른 이름으로 부른다.

---

## 7화음의 종류

### 1. 메이저 세븐 (Major 7th / maj7)

**구성**: 메이저 트라이어드 + 장7도

```
C → E → G → B
   장3도 단3도 장3도
```

- **표기**: Cmaj7, CM7, CΔ7 (△ 기호)
- **느낌**: 따뜻하고 몽환적, 떠다니는 듯한 느낌. 안정적이지만 약간 꿈같음
- **장르**: 팝 발라드, 재즈, 보사노바, 시티팝
- **예**: "Just The Two Of Us" 계열 코드 진행에서 자주 등장

> 주의: Cmaj7 ≠ C7. C7은 도미넌트 세븐이다. **maj가 있으면 장7도, 없으면 단7도.**

---

### 2. 도미넌트 세븐 (Dominant 7th / 7)

**구성**: 메이저 트라이어드 + 단7도

```
C → E → G → B♭
   장3도 단3도 단3도
```

- **표기**: C7 (C dominant 7이라고도 함)
- **느낌**: 강한 긴장감, 해결 욕구. 듣는 순간 "다음 코드로 가고 싶다"는 느낌이 강하게 든다
- **장르**: 블루스, 록, 재즈, 소울, 펑크(Funk)
- **역할**: 5도권에서 토닉(I)으로 해결하는 **도미넌트(V) 코드의 핵심**. G7 → C 같은 V7→I 진행

> 블루스 장르에서는 I·IV·V 세 코드를 모두 도미넌트 세븐으로 쓰는 게 오히려 관습이다. (C7-F7-G7) 이론적으로는 "틀린" 진행이지만 블루스의 정체성 그 자체.

---

### 3. 식스 코드 (6th Chord)

**구성**: 메이저 트라이어드 + 장6도

```
C → E → G → A
   장3도 단3도 장2도(!)
```

- **표기**: C6
- **느낌**: 밝고 빈티지한 느낌. 메이저7보다 해상도가 높은 느낌
- **장르**: 보사노바, 스윙 재즈, 복고풍 팝
- **꿀팁**: C6 = Am7/C (Am7 코드를 C를 베이스로 깔면 C6와 구성음이 동일)

> 엄밀히 말하면 6화음은 7화음이 아니라 **6도 음정을 추가한 화음**이지만, 화성학 강의에서 함께 다루는 이유는 "메이저 트라이어드 + 음 하나 추가" 패밀리를 같이 익히기 때문이다.

---

### 4. 디미니쉬 세븐 (Diminished 7th / dim7)

**구성**: 디미니쉬 트라이어드 + 감7도 (전부 단3도!)

```
C → E♭ → G♭ → A (= B♭♭)
    단3도   단3도    단3도
```

- **표기**: Cdim7, C°7
- **느낌**: 극도의 긴장감, 불안, 공포. 고전 공포 영화 BGM의 단골 손님
- **특성**: **완전 대칭 화음** — 어느 음에서 시작해도 단3도 간격이 반복된다. 때문에 C°7 = E♭°7 = G♭°7 = A°7 (전위해도 같은 화음)
- **활용**: 반음 상행/하행으로 다음 코드로 연결하는 패싱 코드로도 자주 쓰임

---

### 5. 하프 디미니쉬 / m7(♭5) (Half-Diminished)

**구성**: 디미니쉬 트라이어드 + 단7도

```
C → E♭ → G♭ → B♭
    단3도   단3도   장3도
```

- **표기**: Cm7♭5, Cø7 (ø 기호)
- **느낌**: dim7보다는 부드럽지만 어둡고 복잡한 색감. 재즈의 성숙한 우울함
- **역할**: 재즈/클래식 단조에서 ii°코드로 사용. **ii°7 → V7 → i** 진행이 단조 ii-V-I의 정석

---

### 6. 오그먼트 세븐 (Augmented 7th / aug7)

**구성**: 오그먼트 트라이어드 + 단7도

```
C → E → G♯ → B♭
   장3도  장3도  감3도(!)
```

- **표기**: Caug7, C7♯5, C7+
- **느낌**: 몽환적이면서 불안정. 보사노바 특유의 "기분 좋은 긴장감"
- **보사노바 진행 예시**: I → Imaj7 → I7 → I6 → (다음 코드)처럼 5음을 반음씩 내리는 크로매틱 진행 안에서 aug7이 징검다리 역할을 함

---

## 종류 한눈에 비교 (C 기준)

| 코드 | 표기 | 구성음 | 느낌 |
|------|------|--------|------|
| C 메이저 세븐 | Cmaj7 | C·E·G·B | 따뜻하고 몽환적 |
| C 도미넌트 세븐 | C7 | C·E·G·B♭ | 긴장, 해결 욕구 |
| C 식스 | C6 | C·E·G·A | 밝고 빈티지 |
| C 마이너 세븐 | Cm7 | C·E♭·G·B♭ | 어둡고 부드러운 긴장 |
| C 디미니쉬 세븐 | Cdim7 / C°7 | C·E♭·G♭·A | 극도의 불안 |
| C 하프 디미니쉬 | Cm7♭5 / Cø7 | C·E♭·G♭·B♭ | 어둡고 복잡 |
| C 오그먼트 세븐 | Caug7 / C7♯5 | C·E·G♯·B♭ | 몽환적 긴장 |

## 다이어토닉 7화음

C장조 다이어토닉 스케일의 각 음에 7화음을 쌓으면:

| 도수 | 코드 | 종류 | 기능 |
|------|------|------|------|
| Imaj7 | Cmaj7 | 메이저 세븐 | 토닉 |
| ii7 | Dm7 | 마이너 세븐 | 서브도미넌트 |
| iii7 | Em7 | 마이너 세븐 | 토닉 |
| IVmaj7 | Fmaj7 | 메이저 세븐 | 서브도미넌트 |
| V7 | G7 | **도미넌트 세븐** | 도미넌트 |
| vi7 | Am7 | 마이너 세븐 | 토닉 |
| viiø7 | Bm7♭5 | 하프 디미니쉬 | (약한 도미넌트) |

> 팝·재즈 편곡에서 3화음 코드를 7화음으로 바꾸는 것만으로도 한층 성숙한 색감이 나온다.

---

## 베이스 연주에서의 활용

- **Cmaj7 위에서**: B음(장7도)을 경과음으로 활용하면 부드럽고 재지한 느낌
- **C7 위에서**: B♭음이 강한 방향성을 가짐 → F 코드로 해결하는 베이스라인에 활용
- **Cdim7**: 반음씩 하행하는 크로매틱 패싱. A → A♭(=Cdim7) → G 같은 연결
- **Cm7♭5**: 재즈 단조 ii-V-I에서 베이스는 루트(C)를 잡고 솔리스트가 위에서 어두운 색감을 만들어줌
- **Caug7**: 보사노바 계열 곡에서 베이스가 G♯ → G로 반음 하행하는 포인트
