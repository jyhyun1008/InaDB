# 텐션 (Tension Notes)

## 텐션이란?

**텐션(Tension)**은 7화음의 코드 톤(1·3·5·7음) 위에 추가로 쌓아 올리는 음을 말한다. 9음, 11음, 13음이 여기에 해당한다.

9음 = 2도를 한 옥타브 위에서 본 것, 11음 = 4도를, 13음 = 6도를 한 옥타브 위에서 본 것. 코드 이름에 괄호 안에 숫자로 표기한다 (예: C7(♭9), Cmaj7(♯11)).

---

## 코드 톤 vs 텐션

| 구분 | 해당 음 | 역할 |
|------|---------|------|
| 코드 톤 | 1, 3, 5, 7 | 화음의 뼈대 |
| 텐션 | 9, 11, 13 (+ 변형) | 색감과 긴장감 추가 |

텐션을 추가할수록 화음의 색감이 복잡하고 풍부해진다. 재즈에서 기본 3·7화음에 텐션을 얹는 것은 거의 필수다.

---

## 텐션과 코드 톤의 관계

| 텐션 | 관계하는 코드 톤 | 메모 |
|------|----------------|------|
| 9음 | 루트(1) | 루트 바로 한 옥타브 위 장2도 |
| 11음 | 3음 | 3음 위 완전4도 |
| 13음 | 5음 | 5음 위 장2도 |

---

## 어베일러블 텐션의 핵심 규칙

> **텐션 음이 관련 코드 톤보다 온음(whole step) 위이면 사용 가능, 반음(half step) 위이면 어보이드.**

- 9음 → 루트(1)와의 관계
- 11음 → 3음과의 관계
- 13음 → 5음과의 관계

이 규칙 하나면 어떤 코드에서 어떤 텐션이 가능한지 그 자리에서 판단할 수 있다. 텐션이 코드 톤과 완전히 같은 음(완전1도, 유니즌)인 경우는 코드 톤 중복이므로 역시 사용 불가다.

---

## 도미넌트 7 (C7 = 1, 3, 5, b7) 기준 텐션 분석

C7의 코드 톤: **C, E, G, Bb**

| 텐션 | 음 (C 기준) | 사용 가능? | 이유 |
|------|------------|-----------|------|
| 9 (자연) | D | ✓ | 코드 톤과 충돌 없음 |
| ♭9 | D♭ | ✓ | 코드 톤과 충돌 없음 |
| ♯9 | D♯ (=E♭) | ✓ | 코드 톤과 충돌 없음 |
| 11 (자연) | F | △ | E(3음)와 반음 위 → 충돌, 보통 기피음 처리 |
| ♭11 | F♭ (= **E**) | ✗ | **3음 E와 동일한 음** → 텐션 불가 |
| ♯11 | F♯ | ✓ | 코드 톤과 충돌 없음 |
| 13 (자연) | A | ✓ | 코드 톤과 충돌 없음 |
| ♭13 | A♭ | ✓ | 코드 톤과 충돌 없음 |
| ♯13 | A♯ (= **B♭**) | ✗ | **♭7음 B♭와 동일한 음** → 텐션 불가 |

> **♭11과 ♯13이 사용 불가능한 이유**: 각각 코드 톤(3음·♭7)과 이명동음이기 때문이다. C7에서만 그런 것이 아니라, 어떤 코드든 해당 텐션 음이 코드 톤과 겹치거나 반음 충돌하면 사용 불가다. 코드 종류에 따라 어떤 텐션이 가능한지 달라진다.

## 얼터드(Altered)와 언얼터드(Unaltered)

| 구분 | 의미 | 예 |
|------|------|----|
| 언얼터드 텐션 | ♭이나 ♯ 없이 자연스러운 음 | 9, 11, 13 |
| 얼터드 텐션 | ♭이나 ♯이 붙은 변형된 음 | ♭9, ♯9, ♯11, ♭13 |

**얼터드 도미넌트(Altered Dominant)**는 V7 코드에 얼터드 텐션을 자유롭게 추가한 것으로, 재즈 즉흥 연주에서 핵심 개념이다. C7alt는 코드 톤(C E G Bb)에 얼터드 텐션(♭9, ♯9, ♯11, ♭13 중 하나 이상)을 쌓은 것.

## C장조 다이어토닉 7화음별 어베일러블 텐션

각 다이어토닉 7화음은 대응하는 모드의 음계를 사용한다. 텐션이 코드 톤보다 온음 위이면 ✓, 반음 위이면 ✗(어보이드).

| 코드 | 모드 | 9 vs 루트 | 11 vs 3음 | 13 vs 5음 | 사용 가능 텐션 |
|------|------|-----------|-----------|-----------|--------------|
| **Cmaj7** | 아이오니안 | C→D 온음 ✓ | E→F 반음 ✗ | G→A 온음 ✓ | **T9, T13** |
| **Dm7** | 도리안 | D→E 온음 ✓ | F→G 온음 ✓ | A→B 온음(★) | **T9, T11** |
| **Em7** | 프리지안 | E→F 반음 ✗ | G→A 온음 ✓ | B→C 반음 ✗ | **T11** |
| **Fmaj7** | 리디안 | F→G 온음 ✓ | A→B 온음 ✓ | C→D 온음 ✓ | **T9, T♯11, T13** |
| **G7** | 믹소리디안 | G→A 온음 ✓ | B→C 반음 ✗ | D→E 온음 ✓ | **T9, T13** |
| **Am7** | 에올리안 | A→B 온음 ✓ | C→D 온음 ✓ | E→F 반음 ✗ | **T9, T11** |
| **Bm7♭5** | 로크리안 | B→C 반음 ✗ | D→E 온음 ✓ | F→G 온음 ✓ | **T11, T♭13** |

★ Dm7의 13(B)는 온음 관계지만 **조건부 어보이드**로 취급한다. B자연음이 단조 분위기와 어울리지 않거나 다른 성부와 충돌하는 경우가 많아, 초급~중급 단계에서는 피하는 것이 안전하다.

### 특이 케이스 상세

**Em7 (T11만):**
프리지안 특성(b2, b6) 때문에 9도(F)와 13도(C)가 모두 코드 톤과 반음 관계가 된다. 사용 가능한 텐션이 T11 하나뿐인 "텐션 빈곤" 코드. 재즈 편곡에서 Em7을 처리하기 까다로운 이유다.

**Fmaj7의 T♯11:**
F 리디안의 특징음인 B(♯4)가 3음(A)보다 온음 위이므로 T♯11로 사용 가능하다. 이 ♭11이 Fmaj7에 리디안 특유의 몽환적 색감을 준다. 같은 코드 구조의 Cmaj7(아이오니안)에서는 11=F가 어보이드지만, FMaj7(리디안)에서는 ♯11=B가 허용되는 것이 흥미로운 차이다.

**Bm7♭5의 T♭13:**
5음이 ♭5(F)이기 때문에 13도도 반음 낮아진 ♭13(G)이 된다. F→G는 온음이므로 T♭13 사용 가능.

## 주요 코드 타입별 어베일러블 텐션 (요약)

| 코드 종류 | 코드 톤 | 사용 가능한 텐션 |
|-----------|---------|----------------|
| Cmaj7 (아이오니안) | C E G B | **T9, T13** |
| Fmaj7 (리디안) | F A C E | **T9, T♯11, T13** |
| G7 (믹소리디안) | G B D F | **T9, T13** (+ 얼터드 텐션 ♭9·♯9·♯11·♭13) |
| Dm7/Am7 (도리안/에올리안) | — | **T9, T11** |
| Em7 (프리지안) | E G B D | **T11만** |
| Bm7♭5 (로크리안) | B D F A | **T11, T♭13** |

> G7(도미넌트 세븐)은 다이어토닉 텐션(T9, T13)에 더해 얼터드 텐션(♭9, ♯9, ♯11, ♭13)도 사용 가능하다. 이 때문에 V7 코드가 가장 다채로운 텐션 선택지를 갖는다.

---

## 텐션 표기법

코드 이름 뒤에 괄호로 표기한다:

```
C7(♭9)       — C 도미넌트 7에 ♭9 텐션 추가
Cmaj7(♯11)   — C 메이저 7에 ♯11 텐션 추가 (리디안 느낌)
C13          — C7에 9·11·13 전부 쌓은 13화음
C7(♭9,♭13)  — 얼터드 도미넌트
```

---

## 베이스에서의 활용

- 텐션 음을 알면 **코드 위에서 어떤 음이 안전한지** 파악 가능
- 베이스라인에서 코드 톤 → 텐션 음 → 다음 코드 톤으로 이동하는 라인: 재즈 워킹 베이스의 기본 구조
- C7(♯11) 위에서 F♯을 경과음으로 넣으면 리디안 도미넌트 느낌 → 보사노바·재즈 퓨전에서 자주 쓰임
- ♭9 텐션: D♭음을 베이스 경과음으로 넣으면 강한 반음 하행 긴장감 → C → D♭ → C(다음 코드) 같은 크로매틱 리턴
