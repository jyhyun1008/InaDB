# 텐션 (Tension Notes)

## 텐션이란?

**텐션(Tension)**은 7화음의 코드 톤(1·3·5·7음) 위에 추가로 쌓아 올리는 음을 말한다. 9음, 11음, 13음이 여기에 해당한다.

9음 = 2도를 한 옥타브 위에서 본 것, 11음 = 4도를, 13음 = 6도를 한 옥타브 위에서 본 것. 코드 이름에 괄호 안에 숫자로 표기한다 (예: C7(♭9), Cmaj7(♯11)).

---

## 코드 톤 vs 텐션

| 구분 | 해당 음 | 역할 |
|------|---------|------|
| 코드 톤 | 1, 3, 5, 7 | 화음의 뼈대 |
| 텐션 | 9, 11, 13 (+ 변형) | 색감과 긴장감 추가 |

텐션을 추가할수록 화음의 색감이 복잡하고 풍부해진다. 재즈에서 기본 3·7화음에 텐션을 얹는 것은 거의 필수다.

---

## 텐션과 코드 톤의 관계

| 텐션 | 관계하는 코드 톤 | 메모 |
|------|----------------|------|
| 9음 | 루트(1) | 루트 바로 한 옥타브 위 장2도 |
| 11음 | 3음 | 3음 위 완전4도 |
| 13음 | 5음 | 5음 위 장2도 |

---

## 어베일러블 텐션의 규칙

모든 텐션이 어떤 코드에서든 쓸 수 있는 것은 아니다. **텐션은 코드 톤과 같은 음이거나 반음 관계(장2도 이내 충돌)이면 사용 불가**다.

- **같은 음**: 텐션이 코드 톤과 이명동음이면 그냥 코드 톤 반복일 뿐 → 텐션 의미 없음
- **반음 충돌**: 텐션이 코드 톤보다 반음 위에 있으면 심한 불협화음이 생겨 화음 색감이 망가짐

---

## 도미넌트 7 (C7 = 1, 3, 5, b7) 기준 텐션 분석

C7의 코드 톤: **C, E, G, Bb**

| 텐션 | 음 (C 기준) | 사용 가능? | 이유 |
|------|------------|-----------|------|
| 9 (자연) | D | ✓ | 코드 톤과 충돌 없음 |
| ♭9 | D♭ | ✓ | 코드 톤과 충돌 없음 |
| ♯9 | D♯ (=E♭) | ✓ | 코드 톤과 충돌 없음 |
| 11 (자연) | F | △ | E(3음)와 반음 위 → 충돌, 보통 기피음 처리 |
| ♭11 | F♭ (= **E**) | ✗ | **3음 E와 동일한 음** → 텐션 불가 |
| ♯11 | F♯ | ✓ | 코드 톤과 충돌 없음 |
| 13 (자연) | A | ✓ | 코드 톤과 충돌 없음 |
| ♭13 | A♭ | ✓ | 코드 톤과 충돌 없음 |
| ♯13 | A♯ (= **B♭**) | ✗ | **♭7음 B♭와 동일한 음** → 텐션 불가 |

> **♭11과 ♯13이 사용 불가능한 이유**: 각각 코드 톤(3음·♭7)과 이명동음이기 때문이다. C7에서만 그런 것이 아니라, 어떤 코드든 해당 텐션 음이 코드 톤과 겹치거나 반음 충돌하면 사용 불가다. 코드 종류에 따라 어떤 텐션이 가능한지 달라진다.

## 얼터드(Altered)와 언얼터드(Unaltered)

| 구분 | 의미 | 예 |
|------|------|----|
| 언얼터드 텐션 | ♭이나 ♯ 없이 자연스러운 음 | 9, 11, 13 |
| 얼터드 텐션 | ♭이나 ♯이 붙은 변형된 음 | ♭9, ♯9, ♯11, ♭13 |

**얼터드 도미넌트(Altered Dominant)**는 V7 코드에 얼터드 텐션을 자유롭게 추가한 것으로, 재즈 즉흥 연주에서 핵심 개념이다. C7alt는 코드 톤(C E G Bb)에 얼터드 텐션(♭9, ♯9, ♯11, ♭13 중 하나 이상)을 쌓은 것.

---

## 주요 코드 타입별 어베일러블 텐션

| 코드 종류 | 코드 톤 | 사용 가능한 텐션 |
|-----------|---------|----------------|
| Cmaj7 | C E G B | 9, ♯11, 13 |
| Cm7 | C E♭ G B♭ | 9, 11, (♭13은 장르에 따라) |
| C7 (도미넌트) | C E G B♭ | 9, ♭9, ♯9, ♯11, 13, ♭13 |
| Cm7♭5 | C E♭ G♭ B♭ | ♭9, 11 |
| Cdim7 | C E♭ G♭ A | (매우 제한적, 보통 그대로 사용) |

> Cmaj7에서 자연 11(F)이 기피음인 이유: F가 E(3음)와 반음 위 충돌을 일으키기 때문. Lydian 모드를 사용하면 이 11이 ♯11(F♯)이 되어 사용 가능해진다.

---

## 텐션 표기법

코드 이름 뒤에 괄호로 표기한다:

```
C7(♭9)       — C 도미넌트 7에 ♭9 텐션 추가
Cmaj7(♯11)   — C 메이저 7에 ♯11 텐션 추가 (리디안 느낌)
C13          — C7에 9·11·13 전부 쌓은 13화음
C7(♭9,♭13)  — 얼터드 도미넌트
```

---

## 베이스에서의 활용

- 텐션 음을 알면 **코드 위에서 어떤 음이 안전한지** 파악 가능
- 베이스라인에서 코드 톤 → 텐션 음 → 다음 코드 톤으로 이동하는 라인: 재즈 워킹 베이스의 기본 구조
- C7(♯11) 위에서 F♯을 경과음으로 넣으면 리디안 도미넌트 느낌 → 보사노바·재즈 퓨전에서 자주 쓰임
- ♭9 텐션: D♭음을 베이스 경과음으로 넣으면 강한 반음 하행 긴장감 → C → D♭ → C(다음 코드) 같은 크로매틱 리턴
