# 5도권 (Circle of Fifths)

## 5도권이란?

**5도권(Circle of Fifths)**은 12개의 모든 키(조)를 **완전5도** 간격으로 원형으로 배열한 음악 이론 도구다. 조표, 전조, 코드 진행 등을 직관적으로 파악하는 데 쓰인다.

```
           C (0)
      F (1b)     G (1#)
   Bb (2b)          D (2#)
 Eb (3b)               A (3#)
  Ab (4b)             E (4#)
      Db (5b)     B (5#)
           F#/Gb (6)
```

- **시계 방향**: 완전5도 상행, **샵(♯)** 증가 (C → G → D → A → E → B → F#...)
- **반시계 방향**: 완전5도 하행 = 완전4도 상행, **플랫(♭)** 증가 (C → F → Bb → Eb → Ab → Db...)

---

## 5도권이 왜 중요한가?

### 조표 파악

5도권의 위치와 조표 개수가 1:1로 대응된다. 악보에 샵이 몇 개 붙어있는지 보면 어떤 키인지 즉시 알 수 있다.

| 위치 | 장조 | 단조 | 샵/플랫 |
|------|------|------|---------|
| 12시 | C장조 | A단조 | 없음 |
| 1시 | G장조 | E단조 | 샵 1 |
| 2시 | D장조 | B단조 | 샵 2 |
| 11시 | F장조 | D단조 | 플랫 1 |
| 10시 | Bb장조 | G단조 | 플랫 2 |

### 가까운 키 = 공통음 많음

5도권에서 **가까울수록** 두 키 사이에 공통음이 많아서 자연스럽게 전조(Modulation)할 수 있다. 멀수록 공통음이 적고 극적인 전조가 된다.

---

## 완전5도 하행 진행

**5도권 반시계 방향** 으로 코드가 이어지는 진행. 음악에서 가장 자연스럽고 "굴러가는" 느낌을 주는 진행이다. 왜냐하면 각 코드의 근음이 다음 코드의 5도음이 되어 **물리적으로 공명하기 때문**.

### C장조의 완전5도 하행 예시

```
C → F → Bb → Eb → ... (5도권 반시계)
```

하지만 조성 안에 머물면서 다이어토닉 코드만으로 하면:

```
G7 → C → F → Bdim → Em → Am → Dm → G7 → C
(V7 → I → IV → vii° → iii → vi → ii → V7 → I)
```

이게 바로 재즈와 클래식에서 자주 쓰이는 **ii-V-I**의 반복 구조다.

---

## Am 기반 완전5도 하행 코드 진행

강의에서 배운: **Am → Dm → G → C → F → Bdim → E → Am**

### 분석

| 진행 | 관계 | 비고 |
|------|------|------|
| Am → Dm | 완전5도 하행 | |
| Dm → G | 완전5도 하행 | |
| G → C | 완전5도 하행 | |
| C → F | 완전5도 하행 | |
| F → Bdim | 감5도 하행 | 완전5도는 아니지만 방향성 같음 |
| Bdim → E | 완전5도 하행 | |
| E → Am | 완전5도 하행 | |

→ **5도권을 한 바퀴 돌며 Am으로 귀환**하는 구조.

### E 메이저 코드의 역할

A 자연단조에서 5도 코드는 Em(마이너)이다. 그런데 이 진행에서는 **E 메이저**가 나온다. 이것이 **화성 단조(Harmonic Minor)**의 원리:

- 자연단조의 7번 음(G)을 반음 올려 G#으로 만들면
- E 메이저 코드(E·G#·B)가 가능해짐
- E → Am 진행에서 G#이 반음 아래 A로 해결되며 **훨씬 강한 귀환감**을 만듦

이 진행이 "아주 괜찮다"는 감상이 딱 맞다. 재즈와 팝을 가리지 않고 쓸 수 있는 강력한 진행이다.

---

## 재즈의 ii-V-I와 5도권

재즈의 핵심 진행 **ii-V-I**도 5도권 원리다:

- C장조에서: **Dm7 → G7 → Cmaj7**
- Dm → G: 완전5도 하행
- G → C: 완전5도 하행

ii-V-I가 여러 키로 연속 등장할 때 (**ii-V-I 연속 전조**) 5도권을 따라 이동한다.

---

## 작곡에서 5도권 활용

1. **키 결정**: 5도권에서 원하는 키를 찾으면 조표와 다이어토닉 코드가 자동으로 결정됨
2. **자연스러운 전조**: 5도권에서 한두 칸 이동하는 전조는 청중이 거의 못 느낄 정도로 자연스러움
3. **강렬한 전조**: 5도권 반대편(예: C → F#)으로 이동하면 극적인 분위기 전환
4. **코드 진행 설계**: 5도권 반시계 방향으로 흐르는 진행은 항상 자연스럽고 "당김"이 있음
