# 당뇨와 인슐린 저항성

> 혈당 조절 메커니즘, 인슐린 저항성, 동양인 위험 요인

---

## 혈당과 인슐린의 기본 작동 원리

### 혈당이란?

우리가 탄수화물을 먹으면 소화 과정에서 **포도당(글루코스)**으로 분해되어 혈액 속으로 들어간다. 혈액 속 포도당 농도를 **혈당(血糖)**이라고 한다. 세포는 이 포도당을 에너지원으로 사용한다.

### 인슐린의 역할

문제는 포도당이 세포막을 마음대로 통과하지 못한다는 것이다. **인슐린(Insulin)**은 **췌장(이자)**의 **베타(β)세포**에서 분비되는 호르몬으로, 세포가 포도당을 흡수할 수 있도록 신호를 보내는 역할을 한다.

비유하자면:
- 포도당 = 열쇠 없이는 못 들어오는 손님
- 인슐린 = 문을 열어주는 안내원
- 세포 수용체 = 문

```
음식 섭취
  → 혈당 상승
  → 췌장에서 인슐린 분비
  → 인슐린이 세포 수용체에 결합
  → 세포문 열림 → 포도당 흡수
  → 혈당 정상화
```

## 인슐린 저항성

### 정의

**인슐린 저항성(Insulin Resistance)**은 인슐린이 분비되어도 세포가 잘 반응하지 않는 상태다. 안내원(인슐린)이 노크를 해도 문(수용체)이 잘 안 열리는 것. 결국 혈당이 떨어지지 않는다.

### 진행 과정

1. 인슐린 저항성 발생
2. 혈당이 잘 안 떨어지자 췌장이 인슐린을 **더 많이** 분비
3. 췌장 베타세포가 과부하로 지쳐 기능 저하
4. 인슐린 분비 자체가 줄어들기 시작
5. 혈당이 만성적으로 높아진 상태 → **2형 당뇨병**

### 주요 원인

| 원인 | 설명 |
|------|------|
| 내장지방 과다 | 지방조직에서 분비되는 사이토카인이 인슐린 신호 방해 |
| 운동 부족 | 근육의 포도당 흡수 능력 저하 |
| 고탄수화물·고당 식이 | 인슐린이 장기간 과다 분비되면 수용체 감수성 감소 |
| 수면 부족 | 코르티솔 증가 → 혈당 상승 → 인슐린 과분비 |
| 만성 스트레스 | 스트레스 호르몬이 혈당 올림 |

## 동양인이 당뇨에 더 취약한 이유

같은 식사를 해도 동양인(한국인·중국인·일본인 등)이 서양인보다 **2형 당뇨 발병률이 높다.** 이유는 다음과 같다.

### 췌장 크기 차이

동양인은 서양인에 비해 **췌장이 작고 인슐린 분비 용량이 낮다.** 혈당 상승에 대응할 수 있는 여유가 적다.

### 내장지방 경향

동양인은 같은 BMI라도 **내장지방 비율이 상대적으로 높다.** 겉보기에는 날씬해 보여도 내장지방이 축적된 **"마른 비만(Skinny Fat)"** 상태일 수 있다.

### 비만 기준의 차이

| 기준 | 비만 판정 BMI |
|------|-------------|
| 서양 (WHO 일반 기준) | 30 이상 |
| 아시아 (WHO 아시아 기준) | 27.5 이상 |
| 한국 (대한비만학회) | 25 이상 |

한국인은 BMI **23** 이상부터 대사 위험도가 유의미하게 올라간다.

## 예방과 식단 관리

### 혈당 스파이크를 줄이는 식이 원칙

| 줄일 것 | 늘릴 것 |
|--------|--------|
| 흰쌀·흰빵·면류 (정제 탄수화물) | 채소·해조류 (식이섬유) |
| 설탕·과당·단 음료 | 단백질 (닭가슴살·두부·계란·생선) |
| 가공식품·트랜스지방 | 잡곡·통곡물 (GI 지수 낮음) |

**식이섬유**는 소화 속도를 늦춰 혈당이 천천히 오르게 한다. 같은 탄수화물도 채소와 함께 먹으면 혈당 반응이 다르다.

### 운동의 효과

근육은 **인슐린 없이도** 포도당을 흡수하는 경로(GLUT4 경로)를 사용할 수 있다. 근육량이 많을수록 혈당 처리 능력이 높아진다. 유산소 운동 + 근력 운동 병행이 가장 효과적이다.
