## 보충 설명

### 1. 코드 넘버링 (코드 포뮬라)

**코드 포뮬라(Chord Formula)**는 어떤 코드든 숫자+기호로 구성 음정을 표현하는 방법이다. 코드 이름을 외우지 않아도 포뮬라만 알면 어떤 키에서든 코드를 즉석에서 만들 수 있다.

→ 자세한 내용: [코드 넘버링](../data/음악이론/코드-넘버링.md)

**규칙 요약:**

| 음정 종류 | 표기 방법 | 예 |
|-----------|-----------|---|
| 장(Major) / 완전(Perfect) 음정 | 숫자만 | 1, 3, 5, 7 |
| 단(Minor) 음정 | 플랫(b) + 숫자 | b3, b7 |
| 증(Augmented) 음정 | 샵(#) + 숫자 | #5 |
| 감(Diminished) 음정 | 더블 플랫 또는 bb | bb7(= 감7도) |

**주요 7화음 포뮬라 비교:**

| 코드 종류 | 포뮬라 | C 기준 구성음 |
|-----------|--------|---------------|
| 메이저 세븐 | 1, 3, 5, 7 | C E G B |
| 도미넌트 세븐 | 1, 3, 5, b7 | C E G Bb |
| 마이너 세븐 | 1, b3, 5, b7 | C Eb G Bb |
| 7sus4 | 1, 4, 5, b7 | C F G Bb |
| m7♭5 (하프 디미니쉬) | 1, b3, b5, b7 | C Eb Gb Bb |
| 오그먼트 세븐 | 1, 3, #5, b7 | C E G# Bb |

### 2. 다이어토닉 코드 7화음

다이어토닉 3화음에 7도를 추가하면 7개의 다이어토닉 7화음이 나온다. 로마 숫자로 표기하면:

```
IM7 — IIm7 — IIIm7 — IVM7 — V7 — VIm7 — VIIm7(b5)
```

C장조로 대입하면: **Cmaj7 — Dm7 — Em7 — Fmaj7 — G7 — Am7 — Bm7♭5**

→ 자세한 내용: [다이어토닉 코드](../data/음악이론/다이어토닉-코드.md)

**5도 하행 전체 진행 (C장조 7화음 버전):**

```
Cmaj7(I) → Fmaj7(IV) → Bm7♭5(VII) → Em7(III) → Am7(VI) → Dm7(II) → G7(V) → Cmaj7(I)
```

각 코드의 루트가 완전5도씩 하행(C→F→B→E→A→D→G→C)하면서 자연스럽게 I로 귀환한다. 3화음 버전에서 7화음 버전으로만 바꿔도 팝 → 재즈 느낌으로 색감이 올라간다.

### 3. EQ 사용법 — 빼기 먼저, 부스트는 나중에

→ 자세한 내용: [이큐 (EQ)](../data/음악/이큐.md)

고음역대를 살리고 싶을 때 하이 부스트만 올리면 오히려 탁하고 과한 느낌이 날 수 있다. 이유는 고음이 안 들리는 원인이 고음 자체가 적어서가 아니라 **다른 주파수들이 고음을 가리고 있기 때문**인 경우가 많기 때문.

핵심 원칙: **"빼기가 먼저, 부스트는 나중에"** (Subtractive EQ first)

1. 고음이 탁하게 들리는 원인이 되는 중역대 주파수를 찾아 컷
2. 그 다음 필요하다면 소량만 하이 부스트
3. 결과적으로 전체 볼륨이 더 작아도 훨씬 깨끗하게 들림
