## 보충 설명

### 1. 텐션 (Tension Notes)

**텐션**은 7화음의 코드 톤(1·3·5·7음) 위에 추가로 쌓는 9·11·13음이다.

→ 자세한 내용: [텐션](../data/음악이론/텐션.md)

텐션으로 쓸 수 있는지의 판단 기준: **코드 톤과 같은 음이거나 반음 충돌하면 불가.**

**C7(1,3,5,b7 = C E G Bb) 기준 텐션 정리:**

| 텐션 | 음 | 가능? | 이유 |
|------|------|-------|------|
| b9 | Db | ✓ | |
| ♯9 | D♯ | ✓ | |
| ♭11 | Fb = **E** | ✗ | 3음 E와 동일 |
| ♯11 | F♯ | ✓ | |
| ♭13 | Ab | ✓ | |
| ♯13 | A♯ = **Bb** | ✗ | b7 Bb와 동일 |

**강의의 질문 — ♭11과 ♯13은 항상 없는 건지, C7에서만 없는 건지?**

결론: C7 전용이 아니라 **"해당 텐션이 코드 톤과 겹치거나 반음 충돌할 때마다" 사용 불가**다. 코드 종류에 따라 어떤 텐션이 가능한지 달라진다. ♭11은 보통 3음(E)과 같은 음이 되어버리고, ♯13은 보통 b7(Bb)과 같은 음이 되어버리는 경우가 많아 사실상 어떤 코드에서도 잘 쓰이지 않는 것이다.

### 2. 대사 엔진 스위치: NEAT와 AMPK

→ 자세한 내용: [운동과 대사](../data/건강/운동-대사.md)

**NEAT**: 정식 운동이 아닌 일상 속 모든 신체 활동(걷기, 청소, 서 있기 등). 식사 후 움직임의 핵심은 칼로리 소모가 아니라 **대사 방향을 지방 저장 → 근육 사용으로 전환**하는 것.

**AMPK**: 세포 안에서 에너지 부족을 감지해 지방 연소 모드로 전환시키는 효소. 현대인은 항상 에너지가 충분한 상태를 유지해 이 스위치가 켜질 기회가 거의 없다. NEAT를 늘리는 것이 가장 현실적인 해법.

**운동과 도파민**: 운동은 내성 없이 도파민을 안정적으로 공급하는 몇 안 되는 행동이다. 항우울제와 비슷한 효과를 내기도 한다. 운동을 "놀이"처럼 느끼게 되면 뇌가 보상으로 인식해 자연스럽게 반복하게 된다.
