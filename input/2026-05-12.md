## 보충 설명

### 1. 펜타토닉 스케일

**펜타토닉 스케일(Pentatonic Scale)**은 7음 음계에서 2개의 음을 제거해 만든 **5음 음계**다.

**메이저 펜타토닉**: 장음계의 **4음(파)과 7음(시)을 제거** → 도레미솔라 (1,2,3,5,6음)

왜 이 두 음을 제거하는가?
- **4음(파)**: 3음(미)과 반음 차이라 코드에 따라 마찰음으로 들릴 수 있음
- **7음(시)**: 루트 바로 반음 아래의 강한 이끎음 → 해결 없이 쓰면 불안정

이 두 음을 빼면 어떤 코드 위에서 연주해도 크게 틀리지 않는 음들만 남아서 **즉흥연주에 압도적으로 많이 쓰인다.**

**마이너 펜타토닉**: 자연단음계의 1,3,4,5,7음 → 라도레미솔

흥미로운 점: C 메이저 펜타토닉(CDEGA)과 A 마이너 펜타토닉(ACDEG)은 **구성음이 완전히 같다.** 시작점만 다른 상대조 관계. 즉 박스 포지션 하나를 외우면 두 스케일 모두 커버 가능하다.

### 2. Logic Pro 12 패턴 리전 신기능

**패턴 리전(Pattern Region)**은 Logic Pro의 스텝 시퀀서 기반 리전으로, 드럼 머신처럼 그리드 방식으로 패턴을 만드는 기능이다.

Logic Pro 12에서 추가된 핵심 신기능:

- **키 트래킹**: 패턴 안의 음들이 프로젝트 키에 맞춰 자동 조정
- **코드 트랙 트래킹**: Logic의 코드 트랙과 연동해서, 코드가 바뀔 때마다 패턴의 음들이 **해당 코드의 코드톤으로 자동 이동**

즉, 베이스나 아르페지오 패턴의 음정을 코드마다 일일이 수정하지 않아도 된다. 코드 트랙에 진행을 입력해두고 패턴 리전에서 리듬만 짜면, 음정은 알아서 따라간다.

### 3. 단 음식과 스트레스

단 음식이 스트레스를 해소해준다는 건 **반은 맞고 반은 틀린** 말이다.

**(1) 단기 보상**: 단 음식 → 도파민·엔도르핀 분비 + 혈당 상승 → 일시적 기분 개선. 하지만 스트레스의 **총량은 그대로**다.

**(2) 혈당 스파이크 → 스트레스 호르몬**: 혈당이 급상승 후 인슐린 과다 분비로 급락하면, 뇌가 이를 위기로 인식해 **코티졸·아드레날린(스트레스 호르몬)**을 분비시킨다. 먹기 전보다 더 불안해지는 이유.

**(3) 만성 염증 → 우울증**: 혈당 스파이크가 반복되면 만성 염증이 생기고, 이는 우울증 발병 위험과 연관된다.

대안: 스트레스를 받을 때는 단 음식 대신 견과류·다크초콜릿 등 혈당이 천천히 오르는 간식으로, 또는 짧은 산책·음악·호흡 조절로 실질적인 스트레스 해소를.
