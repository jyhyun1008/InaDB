## 보충 설명

### 1. 7화음 (Seventh Chords)

**7화음**은 3화음 위에 7도 음정을 하나 더 쌓아서 총 4개의 음으로 이루어진 화음이다. 3화음보다 색감이 훨씬 풍부해지고, 재즈·팝·보사노바 등에서 핵심적으로 쓰인다.

→ 자세한 내용: [7화음](../data/음악이론/7화음.md)

---

#### 메이저7 / 도미넌트7 / 6 한눈에 비교

강의에서 나온 "반음씩 내려가면서 외우기" 방법은 옥타브(루트 위 1옥타브 음)를 기준으로 위에서 몇 반음 내려온 음을 얹느냐로 이해하면 쉽다.

| 종류 | 옥타브에서 몇 반음 아래 | 음정 이름 | C 기준 추가되는 음 | 코드 표기 |
|------|------------------------|-----------|-------------------|-----------|
| 메이저7 | 1 | 장7도 | B | Cmaj7 / CM7 |
| 도미넌트7 | 2 | 단7도 | B♭ | C7 |
| 6 | 3 | 장6도 | A | C6 |

세 코드 모두 C-E-G 메이저 트라이어드를 바탕으로 하고, 위에 얹히는 음의 높이만 다르다.

---

#### Cdim7 — 디미니쉬 세븐

```
C → E♭ → G♭ → A(=B♭♭)
    단3도   단3도    단3도
```

단3도(3반음)를 세 번 쌓은 화음. 어떤 음에서 시작해도 같은 구조가 반복되는 **대칭 화음**이다. 12개의 음을 단3도 간격으로 묶으면 3개씩 4묶음이 나오는데, 그 4묶음이 각각 Cdim7·C♯dim7·Ddim7 세 가지(나머지는 같은 음을 다르게 표기한 것)다.

---

#### Cm7(♭5) — 하프 디미니쉬 (반감음 7화음)

```
C → E♭ → G♭ → B♭
    단3도   단3도   장3도
```

디미니쉬7과 달리 마지막 음정이 장3도라 꼭대기 음이 반음 높다. 재즈에서 단조 ii 코드(ii°7)로 매우 자주 쓰인다. 기호로는 **Cø7** 또는 **Cm7♭5**로 표기.

---

#### Caug7 — 오그먼트 세븐

```
C → E → G♯ → B♭
   장3도  장3도  단3도(!)
```

오그먼트 트라이어드(C-E-G♯) 위에 단7도(B♭)를 쌓은 것. 5음이 반음 올라가 있어서 긴장감이 강하다. 보사노바 특유의 부드럽고 몽환적인 진행(I → Iaug → I6 → I7 같은 흐름)에 자주 등장한다.
