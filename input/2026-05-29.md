1. 클래스101 화성학 강의: 하이브리드 코드의 형성 요인 (4가지 형태)
   - F/G → F는 b7, T9, sus4 / G = root → G7sus4
   - Fmaj7/G → F = b7, T9, sus4, T13 / G = root → G7sus4
   - Dm/G → 5, b7, T9 / G = root → G7sus4 (sus4가 없지만 하이브리드로 취급)
   - Dm7/G → Dm7 = 5, b7, T9, sus4 / G = root → G7sus4
   - 하이브리드 의미 설명
      - G는 도미넌트,
      - 서브도미넌트 속성을 가진 코드들 (F, Fmaj7, Dm, Dm7)
      - 이 코드의 성질은 도미넌트이지만, 서브도미넌트 기능을 하는 코드를 섞어서 소리를 변화시킴
   - 하이브리드 코드 넣어서 곡 만들어보기
